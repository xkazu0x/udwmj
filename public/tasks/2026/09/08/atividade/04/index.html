Como Instalar Linux

Instalar o Linux é um processo acessível que começa com a escolha da distribuição adequada para o seu perfil, como o Ubuntu, o Linux Mint ou o Fedora. O primeiro passo prático consiste em acessar o site oficial da distribuição escolhida e baixar a imagem no formato ISO. Essa imagem contém todo o sistema operacional e precisa ser transferida para um pendrive utilizando um software gravador específico, a exemplo do Ventoy ou do Rufus, transformando a unidade USB em um disco de instalação inicializável.

Etapa 1

Com o pendrive pronto, o próximo passo exige reiniciar o computador e acessar o menu de inicialização (Boot Menu) ou a BIOS/UEFI da placa-mãe. Para isso, é necessário pressionar teclas específicas durante a inicialização, como F12, F10, F2 ou Del, dependendo do fabricante do hardware. Na BIOS, é preciso alterar a ordem de boot para priorizar o pendrive e, se necessário, desativar recursos como o Secure Boot caso a placa-mãe apresente restrições para carregar sistemas de terceiros.

Etapa 2

Ao iniciar o computador pelo pendrive, você entrará em um ambiente de testes conhecido como "Live USB", que permite explorar o sistema e verificar o funcionamento de componentes como Wi-Fi e áudio sem modificar o disco rígido. Nele, basta localizar e abrir o ícone de instalação, comumente rotulado como "Instalar o Sistema". Durante esse assistente gráfico, você definirá o idioma, o layout do teclado, a conexão com a rede e as preferências de particionamento do disco. Usuários iniciantes geralmente optam pela instalação automática, que gerencia o espaço em disco de forma guiada.

Etapa 3

A etapa final do assistente solicita a criação do seu perfil de usuário, exigindo a definição de um nome, o nome do computador e uma senha de acesso — fundamental para futuras instalações e tarefas administrativas. Após confirmar essas escolhas, o sistema copia os arquivos necessários e configura o ambiente de trabalho. Concluída essa fase, basta reiniciar a máquina, remover o pendrive quando solicitado e começar a utilizar o novo sistema operacional.
