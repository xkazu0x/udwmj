Projetos

Starfighter

Jogo do tipo shoot'em up desenvolvido completamente em C. O intuito do projeto foi construir os módulos necessários de um simples jogo completamente do zero. Na parte gráfica, foi desenvolvida uma API para renderização com a técnica de rasterização feita pela CPU. Na parte de audio, foi utilizado WASAPI para audio, API feita pela Microsoft para Windows. Técnicas exploradas: gerenciamento de memória com arenas, linked-lists, ring-buffer, rasterizer, texture sampler, threads.
